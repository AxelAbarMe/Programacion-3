# Características de Java


Ideal tener muchas clases pequeñas funcionales y eficientes, antes de tener pocas llenas de código, debido a la mantenibilidad.


- Encapsulamiento
- Abstracción
- Reutilización
- No hay punteros
- Todo son referencias
- Garbage Collector


## Clases y Tipos


- Primitivos
- Envoltorio: Integer, Double, Character
## Herencia
- Herencia simple: extends
- Interfaces: implements
- Poliformismo | override


## Paquetes


- package e import
- Java API organizada en paquetes


## Diseño


- Verificador de Bytecode
- Portabilidad JVM
- APIs robustas y multiplataforma


## Generica


- Generics
- Sintaxis: Map<V,K>


## Evolución


- Lambdas: Programación sin memoria que entrega respuesta en tiempo de ejecución
- Streams: Paquetes de datos


# UX, Usabilidad y Accesibilidad


UX: Usuario interactua con un producto.


- Satisfecho?
- Eficiente?
- Curva de aprendizaje?
- Errores? Que tan amigable es?


Experiencia debe ser total y enteramente. Experiencia debe ser cambiante y debe ser consultada por sus usuarios para evitar ofrecer malos productos.


## Principios


- Enfocarse en usuario
- Consistencia
- Diseño sencillo
- Raíces del producto
- Depende del usuario, no del producto
- Facilidad de uso
- Hacer pruebas
- Menos es más


Pregunte, valide, pruebe, ejecute.


## Usabilidad


Producto puede ser sencillo, barato o elegante, pero el usuario puede ser complejo, sofisticado o buscar sencillez..


### Principios


- Curva de aprendizaje
- Eficiencia
- Memoria
- Errores
- Satisfación


### Usabilidad vs Utilidad vs Útil


- Utilidad es que cumpla su función.
- Usabilidad es que tan fácil es de usar.
- Útil = Usabilidad + Utilidad.


### Cuando aplicar


- Observar usuarios
- Robar a la competencia
- En prototipos
- Migrar a nueva versión
- Cuando tiene la última versión.


## Heurísticas


- Visibilidad del estado del sistema
- Coincidencia entre el sistema y el mundo real (Contexto).
- Control y libertad del usuario.
- Flexibilidad y eficiencia
- Simplicidad
- Permitir salida adecuada del usuario en caso de errores por cuenta propia.


## Accesibilidad


- Discapacidad
- Manejo de todo lo visual, escucha, sensitivos, cognitivos, motrices, diseño, permanente, incidental o ambiental.
